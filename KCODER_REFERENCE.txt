KCODER REFERENCE
================
KCoder is a client-side Fabric mod for Minecraft 26.3: an in-game scripting platform. You write programs in a Python-like language
(files end in .kcd), edit them in an in-game IDE (command /kcoder), and they control the client: read the world, entities and
inventory, press keys, aim the camera, draw in 3D, build GUIs, call events. This file is generated from the mod's live registry,
so every function, type, event and enum listed here exists.

------------------------------------------------------------------------------
1. WHAT THE MOD CONTAINS
------------------------------------------------------------------------------
- Language: Python-like syntax, coroutines (wait/wait_until never block the game), events, modules (implement), try/except,
  lambdas, comprehensions, f-style string interpolation, vec2/vec3 maths, Lua-style enums, typed declarations for the editor.
- In-game IDE (/kcoder): script folders, multi-file projects, syntax highlighting, autocomplete and signature help that know
  every function and type, type inference, code folding, find/replace, error underlines, undo, copy/cut whole line, a log and
  console panel, a debugger (breakpoints, step over/into/out, variable view) and a profiler.
- Game access: entities, blocks, raycasts, inventory, containers, NBT/data components, attributes, boss bars, chat, keys,
  mouse, camera, screenshots, files and JSON.
- 3D drawing: block overlays, boxes, lines, graphs (functions, parametric, surfaces), images in the world, optional
  see-through-walls rendering, colors (rgb/rgba/hsv/hex/lerp).
- Script GUI: rect, oval, line, label, image, icon, textbox, button, progress, checkbox, slider with parents, anchors,
  scale+pixel sizes, clipping, scrolling, dragging, tweens/animations, toasts, and a ui_kit module with ready-made windows.
- Visual GUI editor (/kcoder gui): place Screen Folders, Color Frames, Text, Buttons, Images (PNG, tint, transparency) and
  Textboxes; explorer tree, properties panel, drag to move, handles to resize, undo/redo, saved outside script folders in
  kcoder/gui.json. Scripts reach them by name.

------------------------------------------------------------------------------
2. LANGUAGE SYNTAX
------------------------------------------------------------------------------
Comments:        # to end of line
Numbers:         all numbers are doubles: 3, 2.5, -1
Strings:         "text" or 'text'; interpolation with braces:  "hp is {get_health()}"
Booleans/nil:    true false nil   (True/False/TRUE/None also accepted, any case)
Lists:           xs = [1, 2, 3]   xs[0]   xs[-1]   xs[1:3]   len(xs)   0-based
Maps:            m = {"a": 1, "b": 2}   m["a"]   m.a   keys can be any value, even entities: m[entity] = line
                 missing key reads as nil, so  if not m[k]:  works
Tuples/unpack:   a, b = 1, 2        for i, x in enumerate(xs):
Vectors:         vec3(1, 2, 3), vec2(1, 2); + - * / and .x .y .z, distance(a, b)
Resource ids:    minecraft:allay   minecraft:diamond_sword   (no quotes)

Operators:       + - * / // % **   == != < > <= >=   and or not   in   is
                 x += 1  x -= 1  x *= 2 ...

Control flow:
    if a:            elif b:            else:
    while cond:      repeat 5:          for x in xs:      for i in range(1, 10):   (range is inclusive)
    break  continue  pass  return  exit
    try:  ... except err:  ... finally: ...        assert cond, "message"

Functions:       def add(a, b=1):  return a + b          (also function / fn)
                 f = lambda x: x * 2
                 call a method with  value:method(args)  or  value.method(args)

VARIABLES AND SCOPE
    x = 5            changes variable x wherever it lives (also inside functions and event handlers);
                     if x does not exist yet it becomes a GLOBAL
    local x = 5      a variable of this function/handler only
    local a, b = 1, 2
    const MAX = 3    constant; assigning again is an error
    global total = 5 explicit global (still allowed)
    for-loop variables, comprehension variables and the except variable are always local.

3. TYPICAL PROGRAMS (patterns)
------------------------------------------------------------------------------
Toggle a line to every allay when G is pressed:
    showing = false
    lines = {}
    on_key_press("G"):
        showing = not showing
        if not showing:
            for allay in lines.keys():
                delete(lines[allay])
            lines = {}
    while true:
        if showing:
            for allay in get_entities_in_range(minecraft:allay, 100):
                if not lines[allay]:
                    lines[allay]: line3d = draw_line_3d(get_eye_pos(), get_entity_position(allay), color.rgb(0,50,255), 1, 0.05, true)
                else:
                    lines[allay]:setorigin(get_eye_pos(), get_entity_position(allay))
        wait(0.05)

Control a GUI made in the visual editor (names are the ones shown in the explorer):
    ScreenFolder.enabled = true
    ScreenFolder.MoneyText.text = "000"
    entered = ScreenFolder.Box.text
    ScreenFolder.Icon.texture = "localstorage/textures/icon.png"
    my_label.parent = ScreenFolder         # elements made by script can live inside a Screen Folder too

overlay_block(block:any, shape?:overlay_shape="hitbox", fill?:any, fill_alpha?:number=0.25, outline?:any, outline_alpha?:number=1, thickness?:number=0.03, through_walls?:boolean=false) -> overlay
    Draws an overlay on a block (or a list of blocks) and finds its position by itself. shape: "box" (1x1x1), "hitbox" (the block's outline shape), "model" (follows the real model) or "collision". fill and outline take color.rgb(...), "#RRGGBB" or a name. *_alpha is 0 (invisible) to 1 (solid). thickness is in blocks (0.1 = a tenth of a block).
    example:
        for b in get_blocks_around(6, "minecraft:diamond_ore"):
            overlay_block(b, "model", color.rgb(0, 200, 255), 0.2, color.rgb(255, 255, 255), 1, 0.02)

    example:
        box = box_overlay(vec3(10.5, 64, 3.25), vec3(2, 1, 0.5), color.rgb(255, 0, 0), 0.3, color.rgb(255, 255, 0), 1, 0.05)

# Smooth aiming, written out by hand.
# Each step recalculates the direction, so a moving target is followed,
# and the last step lands exactly on the target.

function aim_nearest():
    target = get_nearest_entity(nil, 30)
    if target == nil:
        print("No entity within 30 blocks")
        return
    print("Aiming at {target.name} ({target.type}), {target.distance} blocks away")
    for n in range(1, 100):
        wait(random(1, 3) / 1000)
        yaw, pitch = get_direction(get_player_eye_pos(), target.center)
        turn_towards(yaw, pitch, 1 / (101 - n))
    print("Done. Crosshair on target: {is_looking_at(target)}")

# The same thing in one line (built in):
function aim_nearest_fast():
    target = get_nearest_entity(nil, 30)
    if target != nil:
        look_at_smooth(target, 100, 1, 3)


----- features/allay.kcd -----
# Feed every allay within 3.5 blocks of your eyes.

function feed_nearest():
    allays = get_entities_in_range(minecraft:allay, 3.5)
    if len(allays) == 0:
        print("No allay within 3.5 blocks")
        return
    slot = find_hotbar_item(minecraft:amethyst_shard)
    if slot == 0:
        print("Put an amethyst shard in your hotbar first")
        return
    hotbar_select(slot)
    for a in allays:
        look_at_smooth(a, 20, 1, 2)
        wait(0.1)
        interact_entity(a)
        wait(0.5)
    print("Fed {len(allays)} allay(s)")

# Put your own elements inside with element.parent = win.body

function window(title, x, y, w, h):
    frame = create_rect(x, y, w, h, "#161A21")
    frame.radius = 6
    frame.border_width = 1
    frame.border_color = "#2B3240"
    frame.draggable = true
    bar = create_rect(0, 0, w, 18, "#222A36")
    bar.parent = frame
    bar.click_through = true
    label = create_text(8, 5, title, "white")
    label.parent = frame
    label.click_through = true
    close = create_button(w - 18, 2, 14, 14, "x")
    close.parent = frame
    body = create_rect(0, 18, w, h - 18, "#00000000")
    body.parent = frame
    body.click_through = true
    return {"frame": frame, "bar": bar, "title": label, "close": close, "body": body}

# Tab buttons with one page each. Show a page with kit:select_tab(t, index).
function tabs(parent, names, x, y, w, h):
    buttons = []
    pages = []
    n = len(names)
    bw = w / n
    for i in range(0, n - 1):
        b = create_button(x + i * bw, y, bw - 2, 16, names[i])
        b.parent = parent
        buttons.append(b)
        page = create_rect(x, y + 20, w, h - 20, "#00000000")
        page.parent = parent
        page.click_through = true
        page.visible = i == 0
        pages.append(page)
    return {"buttons": buttons, "pages": pages}

function select_tab(t, index):
    for i in range(0, len(t.pages) - 1):
        t.pages[i].visible = i == index

# A button that opens a list. Use kit:dropdown_toggle(d) when d.head is clicked and kit:dropdown_pick(d, i) when d.entries[i] is clicked.
function dropdown(parent, x, y, w, options):
    head = create_button(x, y, w, 16, options[0])
    head.parent = parent
    entries = []
    for i in range(0, len(options) - 1):
        entry = create_button(x, y + 16 + i * 16, w, 16, options[i])
        entry.parent = parent
        entry.visible = false
        entry.z = 50
        entries.append(entry)
    return {"head": head, "entries": entries, "options": options, "value": options[0], "index": 0}

function dropdown_toggle(d):
    for entry in d.entries:
        entry.visible = not entry.visible

function dropdown_pick(d, i):
    d.value = d.options[i]
    d.index = i
    d.head.text = d.options[i]
    for entry in d.entries:
        entry.visible = false

# A tour of the language. Press K in game (or run it from the console:
#   cd ./Example/features/
#   ./basics.kcd:run()
# ). Everything it prints shows in the Log panel.

function stats(numbers):
    # A function can return several values.
    return min(numbers), max(numbers), sum(numbers) / len(numbers)

function countdown(n):
    while n > 0:
        print("  {n}")
        n = n - 1
        wait_tick(1)

function run():
    print("--- variables, math, strings ---")
    x = 10
    y = 3.5
    print("x + y = {x + y}, x * y = {x * y}, x / 4 = {x / 4}")
    name = "Steve"
    print("Hello " + name + ", upper: " + upper(name) + ", length {len(name)}")

    print("--- if / elif / else ---")
    if x > 20:
        print("big")
    elif x > 5:
        print("medium")
    else:
        print("small")

    print("--- lists ---")
    items = ["apple", "stone", "diamond"]
    append(items, "gold")
    for item in items:
        if item == "stone":
            continue
        print("  item: {item}")

    print("--- ranges are inclusive ---")
    total = 0
    for i in range(1, 5):
        total = total + i
    print("1+2+3+4+5 = {total}")

    print("--- several return values ---")
    low, high, average = stats([4, 8, 15, 16, 23, 42])
    print("min {low}, max {high}, average {average}")

    print("--- vectors ---")
    a = vec3(0, 0, 0)
    b = vec3(3, 4, 0)
    print("distance {distance(a, b)}, middle {(a + b) / 2}, length of b {magnitude(b)}")
    yaw, pitch = get_direction(a, vec3(0, 0, 10))
    print("direction to +Z: yaw {yaw}, pitch {pitch}")

    print("--- break and wait ---")
    for i in range(1, 100):
        if i > 3:
            break
        print("  i = {i}")
        wait(0.2)

    print("--- wait_tick ---")
    countdown(3)
    print("Tour finished")
